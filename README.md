# Pump.fun Replay Sprint — Paper Bot, Real Ranking

make.fun trading-bot entry: Pump.fun Replay Sprint — Paper Bot, Real Ranking.

An early-bird sniper for the pump.fun bonding-curve replay: it buys only in a coin's first 3 slots, only when exactly 2 distinct non-creator buyers have piled in, the creator bought at most 1 SOL and has not sold, then exits on +10% / -8%, a trailing stop once up 8%, or after 50 slots. Dev-window backtest (grade-local): net +0.0355 SOL, win rate 20.0%, max drawdown 1.0%, 90 round trips on 90 distinct mints.
